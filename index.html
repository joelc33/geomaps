Modelo de Datos en PostgreSQL (Tabla empresas)

Estructura solicitada: Nombre, Rif, Direccion, latitud y longitud implementada con tipos de datos nativos de alta precisión en PostgreSQL:

Campo Tipo PostgreSQL Restricción Descripción
id BIGSERIAL PRIMARY KEY Identificador único
nombre VARCHAR(255) NOT NULL Razón social o nombre comercial
rif VARCHAR(20) UNIQUE, NOT NULL Registro de Información Fiscal (ej. J-00006372-9)
direccion TEXT NOT NULL Ubicación física / domicilio tributario
latitud NUMERIC(10, 7) NOT NULL Coordenada de latitud (-90 a 90)
longitud NUMERIC(10, 7) NOT NULL Coordenada de longitud (-180 a 180)
created_at / updated_at TIMESTAMP DEFAULT NOW() Marcas de tiempo de Laravel Eloquent
Instrucción DDL para Migración de Laravel:
Schema::create('empresas', function (Blueprint $table) {
    $table->id();
    $table->string('nombre');
    $table->string('rif', 20)->unique();
    $table->text('direccion');
    $table->decimal('latitud', 10, 7);
    $table->decimal('longitud', 10, 7);
    $table->timestamps();
});
